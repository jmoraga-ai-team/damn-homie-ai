Install

Pick your AI. Setup is free. You sign in with Google once, and it can only see the files it makes.

The link you paste

https://ai.damnhomie.com/mcp

Name it Damn Homie AI.

Claude

  1. Open Customize, then Connectors.
  2. Tap + Add, then Add custom connector.
  3. Name: Damn Homie AI. URL: the link above. Tap Continue, then Add.
  4. Tap Connect, then Approve, and sign in with Google. Check the Google Drive box (Google leaves it unchecked), then tap Continue.
  5. Start a chat and say: Load my Save Point.

ChatGPT

  1. Open Settings, then Connectors, then Advanced. Turn on Developer mode.
  2. Tap Create. Name: Damn Homie AI. URL: the link above. Authentication: OAuth.
  3. Sign in with Google. Check the Google Drive box (Google leaves it unchecked), then tap Continue.
  4. In a new chat, add the connector and say: Load my Save Point.

Grok

  1. Go to grok.com/connectors. It opens Connect Apps.
  2. Scroll to the bottom and tap Add a custom connector.
  3. Name: Damn Homie AI. Server URL: the link above. Tap Add MCP.
  4. In the pop-up, tap Approve and sign in with Google. Check the Google Drive box (Google leaves it unchecked), then tap Continue.
  5. Start a chat and say: Load my Save Point.

Menu names change as the apps update. If a button has moved, look for "connectors", "custom" or "MCP".

Stop using it

  1. Remove the connector in your AI app.
  2. Go to myaccount.google.com/connections and remove Damn Homie AI.

Your Drive files stay yours. Delete the Damn Homie folder if you want them gone.
